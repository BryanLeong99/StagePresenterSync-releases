# StagePresenterSync releases

Installers for StagePresenterSync, the church stage-monitor app. The source code is private;
installed copies of the app check this repository for new versions.

- **Windows:** `StagePresenterSync-Setup-<version>-win-x64.exe`. Installed copies update themselves
  (**Settings › Updates**).
- **macOS:** `StagePresenterSync-<version>-mac-arm64.dmg` (Apple silicon) or
  `StagePresenterSync-<version>-mac-x64.dmg` (Intel). Open it and drag the app to Applications.

These are unsigned test builds: Windows SmartScreen and macOS Gatekeeper warn on first launch.
Releases are built and published by the source repository's release workflow; do not upload files
here by hand.
